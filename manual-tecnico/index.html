Manual Técnico

Referência completa da tela Parâmetros do sistema do VendaAI.

É aqui que cada empresa define como a plataforma se comporta — impostos, bloqueios, integrações e muito mais. Este manual documenta todas as abas, seção por seção.

Começar pela aba Geral

Sobre

O que são os parâmetros

Configurações que definem o comportamento do VendaAI para cada empresa — sem depender de alterações no código.

Controlam o comportamento

Ligam, desligam ou ajustam recursos: calcular impostos, exigir campos, bloquear pedidos acima do limite de crédito, conectar serviços externos…

  • Valem por empresa
  • Entram em vigor ao salvar
  • Sem nova versão do sistema

Organizados por abas

Cada aba é uma área do sistema (Pedido, Cliente, Estoque…). Dentro dela, seções agrupam os parâmetros por contexto.

  • 16 abas de parâmetros
  • Divididas em seções
  • Uma página por aba

Formatos

Tipos de parâmetro

Independentemente da aba, cada parâmetro assume uma destas formas.

Liga / desliga

Ativa ou desativa um recurso. Ex.: “Cálculo de impostos”.

Valor

Um número ou texto livre. Ex.: prazo mínimo de entrega.

Lista

Uma opção entre valores predefinidos. Ex.: tema padrão.

Múltipla escolha

Vários itens ao mesmo tempo. Ex.: campos obrigatórios.
