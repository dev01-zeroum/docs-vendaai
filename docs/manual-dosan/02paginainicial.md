A **Página Inicial** identifica o ambiente da empresa e apresenta atalhos para as áreas mais utilizadas do Dosan.

</ManualHeader>

## Acessos rápidos

O painel inicial reúne os acessos aos módulos principais da operação:

- **Dashboard**;
- **Rotas**;
- **Distribuição**;
- **Entregas**.

A quantidade e a posição desses conteúdos podem variar conforme a configuração do ambiente. Quando não houver um conteúdo institucional ativo, a área central pode permanecer sem cartões ou comunicados.

## Informações principais

- **Identificação do ambiente** — permite confirmar que o usuário está na empresa correta;
- **atalhos operacionais** — direcionam para Dashboard, Rotas, Distribuição e Entregas;
- **conteúdos e comunicados** — apresentam orientações publicadas para os usuários;
- **vídeo de apresentação** — direciona para o conteúdo introdutório configurado no ambiente;
- **menu lateral** — concentra todos os módulos liberados para o perfil;
- **notificações e conta** — ficam disponíveis na barra superior.

## Como navegar

<ListaCard>

1. Confirme o nome do ambiente e a mensagem exibida na área central.
2. Utilize o menu lateral para abrir o módulo desejado.
3. Consulte o conteúdo ou o vídeo de apresentação quando precisar rever o funcionamento geral.
4. Use **Configurações** somente se o seu perfil for responsável pela manutenção da Página Inicial.

</ListaCard>

## Menu lateral

O menu lateral concentra os módulos operacionais e administrativos. As opções visíveis dependem das permissões do usuário.

Usuários autorizados podem visualizar o botão **Configurações**, utilizado para administrar o conteúdo apresentado na Página Inicial.

:::note Diferença entre acesso e configuração

Os atalhos da Página Inicial servem para navegar pela operação. A criação e a manutenção dos conteúdos são funções administrativas e podem não estar disponíveis para todos os usuários.

:::
