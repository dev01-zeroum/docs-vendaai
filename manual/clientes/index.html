Clientes

Documentação VendaAIhttps://docs.vendaai.com.br/manual/clientes

Cadastro, consulta e gestão da carteira de clientes.

Sobre esta página

O painel da aba Clientes exibe a lista de clientes cadastrados, permitindo a visualização de informações detalhadas.

Lista de clientes​

A interface apresenta um campo de pesquisa no topo, facilitando a localização de clientes específicos.

Os clientes são organizados em uma tabela estruturada, com colunas que exibem dados como nome, CPF/CNPJ, telefone, WhatsApp, tipo de cliente, vendedor associado, código e status de atividade.

Cada linha da tabela possui um botão de ações, permitindo interações rápidas com os registros.

Filtros e exportação​

Na lateral direita da tela, há um botão de filtros, que possibilita a segmentação dos clientes conforme critérios específicos. Além disso, estão disponíveis opções para exportação de dados para Excel e criação de novos clientes, tornando a gestão mais eficiente.

Para criar um cliente, é necessário clicar no botão “Criar novo cliente”, como mostrado na imagem a seguir:

Passo a passo para criar um cliente​

  1. Informe o CPF (Pessoa Física) ou CNPJ (Pessoa Jurídica) do cliente.
  2. Selecione o tipo de cliente: Pessoa Física ou Pessoa Jurídica.
  3. Digite o nome completo ou razão social do cliente.
  4. Insira o nome fantasia da empresa (quando aplicável).
  5. Preencha o nome do contato responsável pelo cliente.
  6. Informe o telefone principal, incluindo código do país e DDD.
  7. Caso utilize, insira o número de WhatsApp do cliente.
  8. Informe um e-mail válido para comunicação.
  9. Preencha a data de nascimento do cliente.
  10. Se necessário, informe o RG do cliente.
  11. Selecione o perfil do cliente: consumidor final, revendedor, exportador, produtor rural ou solidário.
  12. Escolha o segmento de atuação do cliente.
  13. Defina o vendedor responsável pelo atendimento.
  14. Caso aplicável, informe o percentual de desconto financeiro concedido ao cliente.
